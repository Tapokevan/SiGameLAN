СИ — Домашняя игра
Windows 10 (1809 и новее) / 11, x64

ЗАПУСК
Установите SI-LAN-Setup.exe на каждом компьютере либо распакуйте переносимую
сборку целиком и запустите SIGame.exe. Среда .NET уже включена.
Для HTML-вопросов используется Microsoft WebView2. Его автономный установщик
включён в SI-LAN-Setup.exe. Для присланного кинопакета HTML не требуется.

ВЕДУЩИЙ
Введите имя и нажмите «Создать комнату». Выберите файл .siq, количество мест
для игроков от 2 до 10. Ведущий занимает отдельное место.
Для человека оставьте флажок «Бот» выключенным. Для бота включите флажок
и выберите персонажа. Нажмите «Открыть комнату» и дождитесь подготовки пакета.
Большие пакеты с AVIF требуют времени на преобразование изображений.
Сообщите друзьям IP своего компьютера, показанный в окне создания комнаты.
Если адресов несколько, используйте адрес Wi-Fi/Ethernet домашнего роутера.

ИГРОКИ
Введите своё уникальное имя, нажмите «Подключиться по IP», введите IP ведущего.
Нажмите «Найти комнату», затем «Войти игроком» и «Готов».
Допускается адрес вида 192.168.1.10 или 192.168.1.10:7000.
Пакет вопросов нужен только ведущему. Медиа передаются по домашней сети.

ИГРА
Ведущий запускает игру после подключения участников.
Игрок выбирает вопрос на табло. Под табло находятся «Пас» и «Ответ».
Для ответа также можно нажать правый Ctrl. Клавиша меняется в настройках.
Отвечайте вслух. У ведущего оценки идут слева направо: −x2, −x1, +x1, +x2.
Коэффициент применяется к стоимости ответа, а в вопросах со ставкой — к ставке.
Ведущий также может поставить игру на паузу, перейти дальше и поправить суммы.
Поддерживаются специальные вопросы, аукционы, финал и компьютерные игроки
из движка SIGame. Апелляции отключены.

МЕНЮ КОМНАТЫ
Справа под карточкой ведущего открываются настройки, чат, списки участников
и управление комнатой. Камеру можно добавить через «Камера VDO.Ninja…».
Вставьте ссылку просмотра вида https://vdo.ninja/?view=STREAM_ID.
Камера появится на карточке. Для VDO.Ninja нужен интернет.
HTML-вопросы из .siq показываются прямо на игровом табло через WebView2.
Отдельного открытия .html на стартовом экране нет.

ЕСЛИ ДРУГ НЕ ПОДКЛЮЧАЕТСЯ
Все компьютеры должны находиться в одной сети. Гостевой Wi-Fi с изоляцией
клиентов может запрещать соединения между компьютерами.
Установщик предлагает разрешить входящие подключения для этой игры
в частной сети Windows. Используются TCP 7000 для игры и TCP 6999 для медиа.
Для переносимой версии разрешите SIGame.exe доступ к частной сети
в запросе брандмауэра Windows. Интернет для локальной игры не требуется.
