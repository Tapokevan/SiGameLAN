# SiGameLAN

Локальная «Своя игра» для Windows 10 и 11 x64 на основе SIGame Владимира Хиля. Один компьютер открывает комнату, друзья подключаются по IP и имени. Игра и медиа из пакета работают по локальной сети без внешнего игрового сервера.

1. Скачайте установщик или переносимую сборку на вкладке Releases.
2. Ведущий выбирает «Создать комнату» и открывает пакет `.siq`.
3. Игроки выбирают «Подключиться по IP» и вводят адрес ведущего.

В комнате до 10 игровых мест и отдельный ведущий. Игроки отвечают вслух. Ведущий выставляет оценку кнопками −x2, −x1, +x1, +x2. Камеры VDO.Ninja подключаются по ссылке просмотра и требуют интернет.

Для разработки нужен .NET SDK 10. Команда сборки и тесты описаны в [BUILD.txt](BUILD.txt). Исходный проект распространяется под [лицензией MIT](SI-master/LICENSE).
