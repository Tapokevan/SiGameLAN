СИ — Домашняя игра. Проверка сборки 15.11.2026

Обновление 1.1. Чёрно-оранжевая тема и новая компоновка комнаты.
В тесте с двумя экземплярами через LAN IP пакет с HTML открылся,
а встроенный HTML отобразился у ведущего и игрока. Проверены новое
расположение кнопок и открытие правого меню. В финальном EXE
кнопка «Ответ» передала ход игроку, а +x2 начислила 200 за вопрос 100.
Порядок оценки в окне ведущего: −x2, −x1, +x1, +x2. Камеры VDO.Ninja
используют существующие видеоаватары. Живой поток не проверялся.

Ниже результаты первоначальной проверки движка и кинопакета.

Собрана автономная Windows x64 версия на исходниках SIGame 7.13.12.
Исполняемый файл: SI-LAN/SIGame.exe. .NET 10 включён в сборку.

Проверено:
• Два отдельных процесса EXE: ведущий и игрок, соединение через 192.168.0.106:7000.
• Открытие исходного Chernoslivnaya_kino_Solyanka_20_Imeni_Maykla_Beya.siq.
• Штатный разбор всех 4 раундов и 175 вопросов пакета.
• Создание комнаты, вход по IP и имени, готовность, запуск партии.
• Выбор вопроса игроком, передача изображений, кнопка ответа RightCtrl.
• У ведущего появились +x1, −x1, +x2, −x2; нажатие +x2 для вопроса 600
  начислило 1200, одинаковый счёт отображался в обоих окнах.
• Изображение AVIF после преобразования отдаётся как PNG: HTTP 200,
  Content-Type image/png, правильная PNG-сигнатура.
• Аудио MP3 и видео MP4 передаются по LAN с поддержкой Range: HTTP 206.
• Проверка 10 свободных мест и переключения человека/бота прошла.
• Набор тестов движка: 25 пройдено, 1 заранее отключён в исходном проекте.
• Дополнительные тесты мест и присланного пакета: 2 пройдено.
• После исправления множителей выполнены отдельные сценарии +x1, −x1,
  +x2, −x2: 4 пройдено, 0 ошибок.
• Установщик успешно скомпилирован Inno Setup. Архивы ZIP проверены по CRC.

Границы проверки:
Оба экземпляра запускались на одном физическом компьютере через его LAN-IP.
Второй физический ПК, отдельная Windows 10 и установка на чистую систему
в этой среде не проверялись. Все 175 вопросов вручную не проигрывались.
Передача MP3/MP4 проверена; воспроизведение каждого медиаролика не проверялось.
Нативное воспроизведение аудио/видео использует компоненты Windows.
Внешние ссылки внутри сторонних пакетов могут требовать интернет.

Поставка:
SI-LAN-Setup.exe — установщик с автономным WebView2.
SI-LAN-Portable.zip — распаковать целиком, запускать SIGame.exe.
SI-LAN-Source.zip — изменённые исходники и инструкция сборки.
SHA256SUMS.txt — контрольные суммы трёх файлов.

Локальная сеть: TCP 7000 для игры, TCP 6999 для медиа.
Установщик предлагает правило брандмауэра только для частной локальной сети.
